QUIZ MASTER - START HERE

This version is a single-file website. The full design and quiz logic are already inside index.html.

HOW TO OPEN ON YOUR LAPTOP
1. Extract the ZIP file.
2. Double-click index.html. If it opens in Notepad, right-click index.html > Open with > Chrome or Microsoft Edge.
3. The browser should show Welcome to Quiz Master, a name box, Start Quiz, and the leaderboard. It should NOT show HTML code in the browser.
4. Enter a name > Start Quiz > choose General Knowledge or Aptitude. Each category has 20 questions.
5. Each correct answer gives 1 point. The result screen displays score, correct/wrong answers, and accuracy.

HOW TO PUBLISH ON GITHUB PAGES
1. Extract the ZIP.
2. Create a new public GitHub repository, for example quiz-master-website.
3. Use Add file > Upload files and upload ONLY index.html from this folder, then Commit changes.
4. Open Settings > Pages. Select Deploy from a branch, Branch main, Folder /(root), then Save.
5. Once published, click Visit site. The link will work on phone and laptop with internet access.

IMPORTANT
- You only need index.html for the website. You do not need to upload this README file.
- The leaderboard is saved locally in the current browser/device. It is not a shared/global leaderboard yet. A shared cross-device ranking needs an online database.
- If you edit or upload the page, make sure the file name is exactly index.html.
